# Day-1 Visual Design Guide

_UTA-branded visual system for the March 26 collaborative presentation_
_Prepared March 19, 2026_

## Purpose

This guide translates UTA's current branding rules into a presentation system for the Day 1 cluster deck.

The deck should feel:

- institutional, not corporate
- regionally grounded, not generic sustainability
- collaborative, not four mini-presentations stitched together
- polished enough to signal leadership, but simple enough to build in a 2-hour room session

## Design Direction

Use a **blue-led UTA system** with orange as a controlled accent.

The visual tone should be:

- white backgrounds or very light neutral backgrounds
- strong blue structure for headings, dividers, charts, and maps
- orange only for emphasis, deadlines, highlights, and key callouts
- Texas/DFW maps, infrastructure diagrams, and clean matrices instead of stock-photo-heavy slides
- a recurring **spire** motif that signals ascent, coordination, and institutional ambition

## Official UTA Guardrails

These are the rules that matter most for this presentation:

- Use the **main UTA logo with wordmark** as the official logo when the university logo appears.
- Do **not** redraw, rearrange, stack, or recolor the logo.
- Keep clear space around the logo equal to the width of the `T` crossbar.
- Minimum logo size: `0.375"` in print or `50 px` on screen.
- Do **not** use the Athletics `UT Arlington` wordmark for academic or university-wide presentation materials.
- Do **not** use the seal without permission.
- Do **not** create a separate cluster logo. The Day 1 presentation can have a title, but not a new mark intended to function as a logo.

## Spire Motif System

The word **"spire"** is central to the cluster-hire call, so it should appear as a recurring visual idea across the deck.

The key rule is:

- use the spire as a **motif and layout language**
- do **not** turn it into a separate logo, badge, or academic-center mark

### What the Spire Should Mean Visually

The spire motif should communicate:

- upward movement
- convergence into a shared apex
- multiple inputs becoming one visible structure
- growth from pilot work to institutional prominence

### Approved Spire Forms for This Deck

Use one or more of these forms:

- a set of four vertical bands converging toward a narrower apex
- a stepped or stacked triangular rise
- a central vertical axis with widening base layers and a pointed top
- a ladder, timeline, or funding sequence that resolves upward into a capstone shape

### Do Not

- design a new symbol that looks like an official cluster logo
- use church-spire or gothic imagery
- use literal clip-art towers
- overuse pointed shapes so aggressively that the deck starts looking like a startup pitch

### Color Treatment for the Spire Motif

- main spire geometry should be in `UTA Blue`
- use `UTA Orange` only for one of these:
  - apex highlight
  - deadline marker
  - key stage highlight
  - final capstone line

### Placement Rules

- the spire motif can appear on many slides, but in different levels of intensity
- use the strongest spire treatment on Slides `1`, `8`, and `16`
- use subtler spire echoes on Slides `3`, `9-13`, and the rollout slides
- avoid repeating the exact same spire graphic unchanged on every slide

### Practical Rule

For this deck:

- use **blue, black, or white** for all essential text
- use **orange primarily as an accent**
- avoid putting critical text in orange on white, white on orange, blue on orange, or orange on blue

Use these only to support the blue/orange system, not replace it.

## Typography System

### Preferred Brand Fonts

- `Frutiger 55 Roman` is UTA's primary design font.
- Within Frutiger, bold and light weights are preferred over ultra or condensed.

### Practical Slide Fallbacks

If Frutiger is not available:

- use `Arial` or `Helvetica`

### Digital-Friendly Optional Alternatives

If Adobe fonts are available and the deck is being built digitally:

- use `Noto Sans` for most headings and body text
- use `Noto Sans ExtraCondensed` sparingly for section labels or short campaign-style emphasis
- use `Minion Pro` only for rare serif pull quotes or formal subheads

### Recommended Slide Type Scale

| Element | Size | Weight | Notes |
|--------|------|--------|-------|
| Title slide headline | 28-36 pt | bold | short and direct |
| Section label | 14-18 pt | bold / uppercase | use sparingly |
| Standard slide title | 24-30 pt | bold | sentence case preferred |
| Body bullets | 18-22 pt | regular | max 3 bullets on content slides |
| Small labels / chart notes | 12-16 pt | regular or semibold | never below projector legibility |
| Footer / source note | 10-12 pt | regular | only when necessary |

### Type Rules

- Prefer sentence case over all caps for main titles.
- Use short, declarative titles.
- Avoid mixing more than two font families in the deck.
- Do not use decorative display fonts for body text.

## Logo and Wordmark Usage

### Recommended Placement

- **Slide 1:** full main UTA logo with wordmark
- **Slide 16:** main UTA logo with wordmark or small closing treatment
- Optional: a small initials logomark on section-divider slides only if using the approved asset

### Do Not

- use the logo on every slide
- squeeze the logo into crowded funding or timeline slides
- create a "Texas Sustainability Research Collaborative" logo treatment that behaves like a separate identity
- use the Athletics mark or Blaze in academic-cluster materials

## Slide Master Recommendations

- Format: `16:9`
- Base background: white
- Top margin: clean, generous whitespace
- Left alignment: default for nearly all slide titles and body content
- Use a thin UTA Blue rule or small blue block to anchor section titles
- Use orange only for one focal element per slide

### Master Components

- Title area in top-left
- Optional short section kicker above title
- Content zone below, using either:
  - one-column narrative
  - two-column comparison
  - grid of cards
  - horizontal timeline
- Footer only when needed for source or logo

### Optional Master Motif

If the deck is built from a slide master, add one subtle motif:

- a faint blue vertical line or tapered shape in the far-right margin
- or a thin ascending corner shape that hints at a spire without distracting from content

Keep opacity low enough that it does not interfere with charts, maps, or text.

## Recommended Slide Archetypes

### 1. Title / Framing Slides

Use for Slides `1-3`

- white background
- bold blue title
- one strong diagram or map
- no more than 3 bullets
- allow the clearest spire silhouette or convergence motif here

### 2. Pilot Project Slides

Use for Slides `4-5`

- left column: research question and outputs
- right column: visual or flow diagram
- bottom or side strip: 3-4 funding tags

Funding tags style:

- white pills with blue border
- one orange accent rule or orange label for deadline-sensitive items

### 3. Student / Pedagogy Slides

Use for Slides `6-7`

- pipeline diagram or stacked stages
- blue headers, gray supporting lines
- one orange emphasis node only

### 4. Funding Architecture Slides

Use for Slides `8-13`

- avoid spreadsheet look
- use cards, lanes, and labeled phases
- make ownership and sequence visually obvious
- use the spire idea as an organizing principle: the funding system should feel like an ascent, not a list

### 5. Rollout / Closing Slides

Use for Slides `14-16`

- timeline bars, milestone cards, or a compact metric board
- visual density slightly reduced to help the ending breathe

## Funding Slide Design Rules

The funding slides are the most likely place for the deck to get visually overloaded. Use the rules below.

### Slide 8: Funding Strategy

Use a **3-stage ladder that builds into a spire**:

- `Seed and Pilot`
- `Scale and Convergence`
- `Flagship Growth`

Visual treatment:

- blue stage blocks or ascending tiers
- orange thin underline or apex highlight
- one large number only: `$7.5M-$15M`

Do not place more than 4 bullets on this slide.

### Slide 9: Year 1 Federal Funding Sources

Use **4 or 5 grant cards**, not a table.

Card structure:

- top line: agency
- main line: program acronym
- subline: one short fit statement
- micro line: deadline or timing

Recommended card order:

1. `NSF DRMS`
2. `NOAA BAA`
3. `USDA AFRI`
4. `NSF Environmental Sustainability`
5. `NEH Collaborative Research` as optional smaller card

Color system:

- card title in blue
- deadline chips in orange
- body copy in dark neutral

Optional motif:

- align the cards on a slight upward diagonal or under a subtle spire cap so the slide still feels part of the larger visual language

### Slide 10: Texas, Regional, and Foundation Funding Sources

Use a **Texas Advantage** layout:

- left: simplified Texas or DFW map
- right: stacked cards for `Meadows`, `NCTCOG`, `GLO`, `IRP`, and one Texas-agency lane

Recommended visual emphasis:

- Meadows as the largest non-federal card
- NCTCOG highlighted as "existing UTA partner"
- GLO highlighted with the nearest visible date

Optional motif:

- use a narrow spire marker or apex tab above the right-hand funding stack to suggest these sources are feeding the larger cluster build

### Slide 11: Scale and Flagship Funding Sources

Use a **build-up graphic**:

- left: pilot evidence
- center: `NSF S&CC`
- right: `NSF GCR`
- bottom row: monitored pathways (`CAREER`, `Kresge`, `RWJF`, `DOE`, `BRIC`)

Make `GCR` the visual focal point.

This is one of the best slides to let the spire motif become explicit:

- the left-to-right or bottom-to-top movement should visibly resolve into the `GCR` capstone

### Slide 12: Funding Ownership Map

Use a **matrix**, not bullets.

Rows:

- Andrews
- Bray
- Shost
- Marable

Columns:

- Federal
- Texas / regional
- Pilot leadership
- Shared cluster proposals

Use blue row labels and light gray cell rules.

### Slide 13: 18-Month Proposal Timeline

Use a **semester timeline** with three bands:

- `Late Summer / Fall 2026`
- `Late 2026 / Early 2027`
- `2027 Cycle`

Use orange markers for deadlines:

- `Aug. 18, 2026` DRMS
- `Sep. 30, 2026` NOAA
- `Dec. 31, 2026` AFRI
- rolling markers for `Meadows` and `NCTCOG`

This slide should read like a proposal sequence, not a calendar dump.

Spire variation:

- the semester bands can subtly narrow or rise toward the flagship submission stage
- or the timeline can culminate in an apex marker for the convergence proposal

## Chart and Diagram Style

### Charts

- Use `UTA Blue` for the main series.
- Use `UTA Orange` for one key highlight series only.
- Use gray or light blue tints for context series.
- Label bars or lines directly when possible.
- Avoid legends if direct labels will fit.
- Avoid rainbow palettes entirely.

### Flow Diagrams

- Use blue boxes with white text for main steps.
- Use orange connectors or callouts for emphasis.
- Keep connector arrows simple and thick enough for projection.
- When possible, let flows resolve into an upper node rather than a flat end-point. That keeps the spire logic present without becoming repetitive.

### Tables

- Prefer card layouts over raw tables.
- If a table is necessary:
  - blue header row
  - white body rows
  - light gray rules
  - orange only for one emphasis column or deadline tags

## Map Style

Maps are central to this presentation and should feel custom, not default GIS exports.

### Recommended Map Treatment

- base geography in white, very light gray, or pale neutral
- main area of study in blue
- key highlight geography in orange
- labels in dark blue or deep neutral
- if multiple overlays are needed, use blue scale plus pattern or stroke variation instead of random colors

### Avoid

- default ArcGIS palettes
- bright greens and purples
- heavy satellite imagery
- cluttered legends

### Best Uses in This Deck

- Slide 2: Texas / DFW challenge map
- Slide 4: infrastructure systems geography
- Slide 5: land-use / floodplain / development geography
- Slide 10: Texas funding ecosystem or regional partnership map

## Photography and Image Use

If photos are used, they should support place and credibility.

Use:

- Texas infrastructure
- waterways / flood control / urban growth
- fieldwork, planning, community, transit, or regional landscapes

Avoid:

- generic green-energy stock art
- campus brochure clichés unless directly relevant
- crowded collages

If a photo background is used:

- apply a deep blue overlay at high transparency
- keep text in white
- avoid orange text over photos

## Section-by-Section Visual Plan for the 16-Slide Deck

### Slides 1-3

- white background
- blue structural elements
- one strong diagram or map each
- strongest early use of the spire motif: convergence, shared apex, institutional ambition

### Slides 4-5

- project-specific diagrams with funding tags
- one clear orange highlight only
- use quieter spire echoes, such as tapered flow or rising side geometry

### Slides 6-7

- pipeline graphics
- lighter density
- one upward path is enough; do not force a pointed shape on every student slide

### Slides 8-13

- the most information-rich section
- card systems, matrices, and timelines
- no dense paragraphs
- strongest structural use of the spire motif after the opener
- these slides should visually suggest progression toward a capstone funding outcome

### Slides 14-16

- wider spacing
- milestone bars and dashboard-style metrics
- cleaner close with reduced visual clutter
- close with a final spire or apex gesture on the last slide to visually complete the presentation

## Accessibility Rules for This Deck

- Use blue/black/white for essential text.
- Use orange as an accent, not the main reading color.
- Do not rely on color alone to show meaning; use labels, icons, or shape differences too.
- Keep body text large enough for projection.
- Check contrast if using orange text at all.
- Use simple charts with direct labels and minimal legend dependence.

## Practical Build Rules for the 2-Hour Session

- Build a master slide with title, blue rule, and footer first.
- Lock the type system early so the group does not improvise fonts slide-by-slide.
- Build grant slides with reusable cards so programs can be swapped quickly.
- Put one person in charge of color discipline.
- If time runs short, simplify by cutting content, not by adding tiny text.

## Production Checklist

- Confirm official UTA logo file before final export.
- Verify logo clear space on title and closing slides.
- Replace any non-brand colors in charts.
- Check all orange text for contrast or convert it to blue.
- Test the deck on a projector or external monitor if possible.
- Export a PDF backup in case fonts shift.
